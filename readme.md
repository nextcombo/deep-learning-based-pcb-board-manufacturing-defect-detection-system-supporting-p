# Deep learning-based PCB board manufacturing defect detection system, supporting PCB board burrs, breaks

## Body

Deep learning-based PCB board manufacturing defect detection system, supporting the recognition of defects such as burrs, short circuits, pinholes on PCB boards. AI project No. 10661

This project is implemented based on the YOLOv11n lightweight model, featuring lightweight design, fast inference speeds, and is suitable for real-time detection. It supports both image/batch image detection, visualizes the detection results, and provides a complete training, testing, and inference process.

The dataset includes common defect types in PCB production: leakage, short circuit, short circuit, pinhole, foreign matter, open circuit, burr, etc. The dataset has been labeled and divided into training set, validation set, test set according to the YOLO format.

Tech Stack: Deep learning framework PyTorch, target detection model YOLO11n, data processing OpenCV, Pillow, development language Python
